
Student Management System using MySQL

About the Project

This is a Student Management System project developed using MySQL and MySQL Workbench. The project demonstrates how SQL queries can be used to create tables, manage student-related data, and retrieve useful information from a database.

Technologies Used

- MySQL
- MySQL Workbench
- SQL

Key Features

- Create and manage database tables
- Insert and retrieve records
- Update and delete data
- Filter and sort records
- Use aggregate functions
- Perform joins between tables
- Write subqueries

SQL Concepts

This project covers fundamental and intermediate SQL concepts, including:

- CREATE DATABASE and CREATE TABLE
- INSERT, SELECT, UPDATE, and DELETE
- WHERE, ORDER BY, and GROUP BY
- Aggregate functions such as COUNT, SUM, and AVG
- JOIN operations
- Subqueries

How to Run

1. Install MySQL and open MySQL Workbench.
2. Download the SQL script from this repository.
3. Open the script in MySQL Workbench.
4. Connect to your MySQL server.
5. Execute the queries in the correct order.

Learning Outcomes

Through this project, I practised database creation, SQL query writing, data management, joins, and subqueries.
